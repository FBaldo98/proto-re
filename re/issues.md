# Открытые проблемы

## #1 Хук `core::Report` (rva 0x0063c750) коррелирует с 60-секундным ожиданием критической секции
Симптом (Wine 11.20 + DXVK): `err:sync:RtlpWaitForCriticalSection section 11315750 ... retrying (60 sec)`,
фоновый поток ждёт секцию, которую держит главный поток. Игра при этом каждый раз доходит до главного меню.

Статистика запусков по 75–85 с:
| Режим | С ожиданием |
|---|---|
| без хуков (`PROTORE_NOHOOKS=1`) | 0 / 3 |
| те же байты записаны обратно (`PROTORE_NULLPATCH=1`) | 0 / 3 |
| только `math::TraceVector` | 0 / 4 |
| только / вкл. `core::Report` | 5 / 10 |

Проверено и исключено:
- замена `Report` ни разу не вызывалась (лог входа пуст во всех запусках);
- переходов внутрь тела функции нет, указателей на неё в данных нет, все 451 ссылка — `call` на начало;
  `FUN_1063c340` вызывается только из неё;
- второй процесс игра не запускает (один PID в логе);
- общая проверка целостности кода маловероятна (хук `TraceVector` не вызывает эффекта).

Не объяснено. Хук выключен по умолчанию (`enabled=false`) до появления стека потоков в момент
ожидания (`winedbg --command "bt all"`, скрипт в истории сессии) или дифференциального теста с реальными вызовами.
